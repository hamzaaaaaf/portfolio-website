# byhamza.dev

My personal site, built as a recreation of the 2011 Xbox 360 dashboard. Live at **[byhamza.dev](https://byhamza.dev)**.

- **Power on**: the 360 S touch button and a startup animation after the real boot sequence (switch it to "Hamza 360" in settings).
- **Dashboard**: bing, home, social, games, projects, apps and settings hubs, laid out to the measurements of the real Metro dashboard. Neighbouring hubs peek in at the edges.
- **Screens**: profile, projects, stats, achievements, my games, pins, recent and system info slide in like dashboard screens.
- **Apps and games** launch through a splash, run full screen, and quit from the Guide's Xbox Home, with the "any unsaved progress will be lost" check for games.
- **DOOM**: the shareware episode on WebAssembly, playable with a controller (XBLA layout), keyboard and mouse, or touch.
- **Internet Explorer**: browse byhamza.dev inside itself with a stick-driven cursor that glows over links, and a Web Hub on Y.
- **Controllers**: Xbox, DualShock 4, DualSense and Switch Pro, all mapped by button position to Xbox names.
- **Achievements**: 39 of them worth exactly 1000 gamerscore, with the unlock notification. Some are secret, and there are cheat codes.
- **Sounds**: synthesised in the browser with Web Audio. A private copy can use its own recordings (see `public/sound.js`).

### Controls

| | Controller | Keyboard |
| --- | --- | --- |
| Move | Left stick, d-pad | Arrow keys |
| Select | A | Enter |
| Back | B | Backspace |
| Switch hubs | LB / RB | `[` / `]` |
| Search | Y | `/` |
| Guide | Guide button, Start, or Back + Start in games | Escape or Home |

## Stack

Plain HTML, CSS and JavaScript with no build step. Hosted on Cloudflare Workers with static assets, D1 for the guestbook and sparks, and a Durable Object for live presence. DOOM runs on [Cloudflare's WebAssembly build of Chocolate Doom](https://github.com/cloudflare/doom-wasm) (GPL-2.0) with the freely distributable shareware `doom1.wad`.

```
public/index.html   the dashboard (generated by tools/gen/dashboard.py)
public/x360.*       dashboard styles and logic
public/sound.js     synthesised sounds
public/pad.js       controller support
public/os.js        achievements, cheats, sparks and presence
public/doom/        DOOM
public/*.html       apps that open inside the dashboard (generated by tools/gen/pages.py)
src/worker.js       /api/leetcode, /api/github, /api/sparks, /api/guestbook, /api/live
db/schema.sql       D1 tables
```

## Run locally

```sh
npx wrangler d1 execute portfolio-db --local --file db/schema.sql
npx wrangler dev
```

Pushing to `main` deploys automatically.

## Guestbook moderation

Set a secret named `ADMIN_KEY` on the Worker (Workers & Pages → portfolio-website → Settings → Variables and Secrets), then open `/review` and enter it to approve or delete entries.
